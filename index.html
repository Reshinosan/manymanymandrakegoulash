About

中村 裕

Birthday : 1994/12/10

Web designer / Web creator

ご挨拶

1994年生まれ。青森県南部町出身。
中学生時代からWebの無限の可能性に魅了され、Web制作を数多く経験し専門学校の卒業制作では準優勝を果たした。IT会社では、技術派遣として多様なシステム開発・運用に携わる一方で、限られた条件下でも最適な表現を追求する適応力と情報設計力を積み重ねた。
また、自社ホームページのスマホ非対応という課題を発見し、社長に直接提案。企画からデザイン、コーディング、そして公開後の管理まで一貫して担当し、現在では一人でサイト運営を任されている。
既存の枠にとらわれず、ユーザーに新たなWeb体験を届け、クライアントのビジョンをWeb上で具現化することに情熱を注いでいる。
